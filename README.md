# Surte para WooCommerce: instaladores para Windows

**Surte** es una aplicación de escritorio para Windows que ayuda a una tienda WooCommerce a llevar su
catálogo y su stock: meter los albaranes de los proveedores (también en PDF o foto), preparar las fichas
de los productos con IA y cambiar precios y stock, siempre revisando los cambios antes de enviarlos a la
tienda.

Aquí solo están los **instaladores**. Para usar la IA y conectar la tienda en un clic hace falta una
licencia de Surte.

## Descargar

La última versión está en [**Releases**](../../releases/latest): descarga `Surte-<versión>-instalador.exe`
y ábrelo.

- Se instala solo para tu usuario de Windows, sin permisos de administrador (Windows 10 u 11 de 64 bits).
- El instalador todavía **no está firmado**, así que Windows puede avisar con «Windows protegió su PC»:
  pulsa **Más información** → **Ejecutar de todas formas**. El navegador también puede preguntar si quieres
  conservar el archivo.
- Cada versión trae su **SHA-256** en las notas, para comprobar que el archivo es el bueno.
- Para actualizar, instala la versión nueva encima: tus tiendas, tus datos y tu licencia se quedan.

WooCommerce es una marca de Automattic. Surte no está afiliado a WooCommerce ni a Automattic.
